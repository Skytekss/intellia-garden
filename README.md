# ИНТЕЛЛИЯ — Платформа мониторинга и прогнозирования зрелости яблок

Веб-платформа визуального мониторинга, бесконтактного спектрального анализа и предиктивного моделирования сроков сбора урожая яблок для умных интенсивных садов.

---

## 🍏 Ключевые возможности

1. **Интерактивная карта сада (`/?tab=map`):**
   - Выделение кварталов сада (Гала, Фуджи, Голден, Ред Делишес) строго по ортофотоплану со съемки БПЛА.
   - Тепловая шкала созревания плодов от 0% до 100%.
   - Управление масштабом (100%, 150%, 200%) и сенсорное тач-панорамирование на планшетах.
   - **Интерактивный паспорт сектора:** инлайн-редактирование физико-химических показателей (сахаристость Brix, твердость мякоти, крахмал, влажность почвы) и экспорт данных в CSV с поддержкой русской кодировки (UTF-8 BOM).
   - График суточной динамики созревания за 4 недели.

2. **Прогнозирование и моделирование сбора (`/?tab=forecasts`):**
   - **Симулятор «Что если?» (What-If):** расчет смещения технологического окна сбора при аномалиях температуры (±5°C) и осадках.
   - **Фенологическая GDD-модель (Growing Degree Days):** отслеживание накопления эффективного тепла ($T_{\text{base}} = 10^\circ\text{C}$) для сортов Гала, Ханикрисп, Голден Делишес, Ред Делишес, Фуджи.
   - **Калькулятор маржинальности сбора:** экономическая модель потерь от недобора калибра при раннем съеме (-10% массы) и осыпания плодов при задержке (до 24% падалицы), интерактивные слайдеры рыночных цен и тарифов РГС-хранилищ.
   - Модальные окна расчетной логистики (тара, сборщики, транспорт) и печатной технологической карты сбора.

3. **Спектральная лаборатория и агрожурнал (`/?tab=data-entry`):**
   - Форма загрузки мультиспектральных данных БПЛА с выбором каналов (RGB, NIR, Red Edge, SWIR).
   - Экспресс-калькулятор индекса Стрейфа ($SI = F / [R \times S]$) со спидометром зон лежкости плодов (РГС, свежий рынок, промпереработка).
   - Интерактивный агротехнический журнал (полив, подкормка, фунгициды) с подтверждением удаления и диплинками.
   - Телеметрия автоматической метеостанции Davis Vantage Pro2 через LoRaWAN.

4. **Центр поддержки и база знаний (`/?tab=support`):**
   - **База знаний и регламенты:** пошаговые иллюстрированные SOP (съемка с DJI Mavic 3M, калибровка спектра, навигация по карте) с поиском и печатью.
   - **Каталог видеоуроков:** интерактивный видеоцентр с On-Demand монтированием (без фоновой буферизации) и таймкодами ключевых шагов.
   - **Live Chat с AI-ботом:** моментальный интерактивный диалог со встроенными быстрыми подсказками агронома.

5. **Дашборд и единый живой контекст:**
   - 4 динамические Bento-карточки (микроклимат, срочный сбор, средняя влажность почвы, статус съемки), реагирующие на переключение ферм в шапке.
   - Полная мультиязычность (Русский / English) на лету по всему приложению.
   - Фильтрация уведомлений по заглушенным категориям из Настроек.

## 🛠 Технологический стек

- **Фреймворк:** React 19, TypeScript 5.9+
- **Сборщик:** Vite 6
- **Стилизация:** Tailwind CSS v4, Lucide React (иконки)
- **Анимации:** Motion (`motion/react`) — строго аппаратные 60 FPS переходы (`transform`, `opacity`)
- **Тестирование:** Vitest, React Testing Library (25 сьютов, 148 тестов)
- **Деплой:** Netlify CI/CD

## 🚀 Быстрый старт

### Требования
- Node.js LTS (версия 20 или новее)
- npm 10+

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу [http://localhost:5173/](http://localhost:5173/).

### Запуск тестов
```bash
npm test -- --run
```

### Проверка типов и сборка в продакшн
```bash
npm run build
```
