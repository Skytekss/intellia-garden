# Передача контекста сессии (Session Handoff)

## 1. Текущее состояние проекта
- **Платформа:** «ИНТЕЛЛИЯ» — веб-система агрономического мониторинга и прогнозирования зрелости яблок.
- **Окружение:** Node.js v24.22.1 LTS, npm 11.19.1.
- **Стек:** React 19, TypeScript 5+, Vite 6, Tailwind CSS v4, Motion, Lucide React, Vitest, React Testing Library.
- **Дизайн-система:** Зафиксирована в `DESIGN_SYSTEM.md`. Классический Responsive Web App интерфейс (без парящего планшетного мокапа).

### Что уже полностью реализовано и протестировано (Шаг 1):
1. **Фундамент и слой типов:** `src/types/index.ts` (строгая типизация без `any`), `src/data/mockData.ts` (данные 5 секторов, погода, профиль хозяйства).
2. **Responsive Shell:**
   - Темно-изумрудный сайдбар (`#05382b`, логотип, навигация с подсветкой `#047857`, виджет погоды `+18°C`, саппорт).
   - Хэдер с селектором фермы («Ферма «Золотой Сад» ⌵»), профилем и уведомлениями.
   - Адаптивное мобильное меню (Drawer) и нижний таб-бар навигации для экранов `< lg`.
3. **Экран «Главная» (Overview):**
   - HeroBanner с фото заката в саду, парящим анимированным дроном и AI-метриками.
   - Сетка Bento из 4 карточек (Дрон, Агротехника, Метео, AI) с микроанимацией hover.
   - Кнопка CTABar «Перейти к карте сада →» с бесшовным переходом на таб `map`.
4. **Тесты и верификация:**
   - 14/14 unit-тестов успешно пройдены (`npm test`).
   - `tsc -b` и `npm run build` компилируются с 0 ошибок.
   - Визуально проверено в Google Chrome на 3 вьюпортах: Desktop (1440×900), Tablet (768×1024), Mobile (iPhone 375×812).

## 2. Следующая задача: Шаг 2 — «Интерактивная карта сада»

**Референс:** `references/photo_2026-10-26_21-35-06.jpg` (базовый кроп подготовлен в `src/assets/garden_map_ref.jpg`).

### Требования к реализации:
1. **Основная область карты (GardenMap):**
   - Ортофотоплан яблоневого сада.
   - 5 интерактивных секторов:
     - Участок 1: 85% (зеленый спектр)
     - Участок 2: 72% (желто-оранжевый спектр)
     - Участок 3: 60% (желтый спектр)
     - Участок 4: 45% (красный спектр)
     - Участок 5: 78% (салатово-зеленый спектр)
   - Подсветка активного участка при клике и ховере, бейджи с процентами зрелости над участками.
   - Инструменты карты: зум (+ / -), переключение слоев, центрирование.
   - Верхняя панель карты: селектор хозяйства, дата съемки (`12.08.2025`), градиентная шкала «Зрелость плодов» (Ниже -> Выше).
2. **Боковая карточка выбранного сектора (SectorDetailPanel):**
   - Карточка информации: Название (например, «Участок 2»), сорт яблок («Фуджи»), площадь («4.2 га»), готовность плодов («72%»), рекомендованная дата сбора («15 – 22 сентября»).
   - Карточка динамики созревания: линейный график созревания по контрольным датам (01.08, 08.08, 15.08, 22.08, 28.08) с точкой текущей готовности.
   - Кнопка «Подробнее →» в изумрудном стиле.
3. **Адаптивность:**
   - На Desktop: двухколоночный layout (карта слева ~70%, карточка деталей справа ~30%).
   - На Tablet / Mobile: карта на всю ширину, карточка деталей снизу или в виде сворачиваемой шторки.

## 3. Обязательный рабочий процесс оркестратора

1. **Анализ и постановка задачи сабагенту:** Делегировать создание компонентов карты и тестов сабагенту через инструмент `invoke_subagent`.
2. **Аудит результатов:**
   - Запуск `npm.cmd test` и `tsc -b`.
   - Запуск сборки `npm.cmd run build`.
   - Проверка визуального рендера и адаптива через headless Chrome на Desktop, Tablet и Mobile.
3. **Исправление замечаний:** Любые найденные дефекты, ошибки типов или переполнения верстки устранять автономно до идеального результата.
4. **Отчет:** Отчитываться пользователю только после полной готовности и проверки экрана.
