# Спецификация дизайна и референса «ИНТЕЛЛИЯ»

Файл референса: `references/intellia_dashboard_reference.png`

## 1. Общая визуальная концепция
Интерфейс представляет собой современный **AgroTech / Smart Orchard Dashboard** в виде "плавающего" планшетного окна с эффектом Glassmorphism на фоне теплого солнечного яблоневого сада.

## 2. Цветовая палитра
- **Dark Forest Emerald (Сайдбар и акцентные кнопки):**
  - Сайдбар фон: `#05382b`
  - Границы сайдбара: `rgba(16, 185, 129, 0.15)`
  - Активная вкладка в меню: `#047857` (с легким свечением)
  - Главная кнопка «Перейти к карте сада»: `#07503b` (hover: `#096047`)
  - Карточка погоды в сайдбаре: `#03261d` с границей `#064e3b`
- **Light Workspace Surface (Основная рабочая область):**
  - Подложка контента: `#f4f7f6`
  - Белые карточки: `#ffffff` с границей `#e2e8f0` и тенью `0 1px 3px 0 rgb(0 0 0 / 0.05)`
  - Заголовки: `#1e293b`
  - Вспомогательный текст: `#64748b`
- **Акцентные маркеры типов данных:**
  - Дрон (спектральные данные): `#10b981` (Изумрудный)
  - Агротехника: `#14b8a6` (Бирюзовый)
  - Метеоданные: `#0284c7` (Небесно-голубой) + `#f59e0b` (Солнце)
  - AI-аналитика: `#8b5cf6` (Фиолетовый)

## 3. Архитектура экранов и компонентов

### Экран 1: Главная (Dashboard Overview)
- **Сайдбар:**
  - Логотип: зеленый росток + «ИНТЕЛЛИЯ» + «Умные решения для вашего сада».
  - Пункты меню: Главная, Карта сада, Данные, Прогнозы, Уведомления, Настройки.
  - Нижний блок: кнопка «Поддержка» и виджет текущей погоды в саду (18°C, Ясно).
- **Шапка:**
  - Лейбл «Сводка по саду» слева.
  - Выпадающий список выбора сада («Ферма «Золотой Сад» ⌵») с аватаром справа.
- **Hero-баннер:**
  - Фото яблоневого сада в золотой час.
  - Анимированный летящий дрон с пульсирующим маячком.
  - Заголовок «ИНТЕЛЛИЯ — Прогнозирование сроков сбора урожая яблок».
  - Поясняющий текст про гиперспектральные данные и ИИ.
- **Bento Grid (4 карточки данных):**
  - 1. Гиперспектральные данные с дрона (анализ состояния деревьев и плодов).
  - 2. Агротехнические данные (полив, удобрения, обработка).
  - 3. Метеоданные (температура, осадки, влажность).
  - 4. AI-аналитика (карта зрелости и рекомендации по сбору).
- **CTA-плашка:**
  - Широкая зеленая кнопка «Перейти к карте сада →» с иконкой листика.

### Экран 2: Карта сада (Interactive Orchard Map)
- Интерактивная карта секторов (A1, A2, B1, B2) с сортами яблок (Гала, Голден, Фуджи, Хани Крисп).
- Индикаторы зрелости плодов в % и прогноз количества дней до сбора.
- Фильтры по сортам и статусу готовности.
