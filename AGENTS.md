# Инструкции для AI-агентов в проекте «ИНТЕЛЛИЯ»

Добро пожаловать в проект **ИНТЕЛЛИЯ** — веб-платформу визуального мониторинга и прогнозирования зрелости яблок для умных садов.

## Контекст проекта
- **Тип проекта:** Visual-First Responsive Frontend (классический Web App без мокапа-планшета на фоне сада).
- **Стек:** Node.js LTS, React 19, TypeScript 5+, Vite 6, Tailwind CSS v4, Motion (`motion/react`), Lucide React.
- **Дизайн-система:** Описана в `DESIGN_SYSTEM.md` и `references/design_spec.md`.
- **Передача контекста и текущий шаг:** `SESSION_HANDOFF.md` и `implementation_plan.md`.

## Обязательные правила разработки
1. **Строгая типизация TypeScript:** Никаких `any`. Все интерфейсы строго описаны в `src/types/`.
2. **Точность дизайна и палитры:**
   - Темно-изумрудный сайдбар: `#05382b`, активный таб `#047857`, виджет погоды `#03261d`.
   - Светлая рабочая область: `#f4f7f6`, белые карточки `#ffffff`.
   - Главная кнопка: `#07503b` (hover: `#096047`).
   - Минимальный размер шрифта — **12px (`text-xs`)**. Никаких микрошрифтов меньше 12px.
3. **Плавные анимации:** Использовать `motion` из библиотеки `motion/react`. Анимировать только `transform` и `opacity` (стабильные 60–120 FPS).
4. **Адаптивность:** Идеальная работа и отсутствие горизонтального скролла на Desktop (1440px+), Tablet (768px–1023px) и Mobile (iPhone 375px). Использовать `min-w-0` для flex-потомков.

## Роль Главного Оркестратора и рабочий процесс
1. **Анализ задачи:** Составить четкий план действий на текущий экран.
2. **Делегирование сабагентам:** Отправлять сабагентов (`invoke_subagent`) писать компоненты, логику и тесты.
3. **Строгий контроль и аудит:**
   - Проверить сгенерированный код на соответствие архитектуре и типам (`tsc -b`).
   - Запустить тесты (`npm test`) и продакшн-сборку (`npm run build`).
   - Проверить верстку и адаптив на всех устройствах через headless Chrome / скриншоты.
4. **Автономное устранение дефектов:** Если обнаружена ошибка, переполнение или несоответствие макету — исправить и перепроверить.
5. **Сдача результата:** Отчитываться пользователю только тогда, когда задача полностью проверена, протестирована и готова к показу.
