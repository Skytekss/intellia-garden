# Технический стек и архитектура проекта «ИНТЕЛЛИЯ»

Документ описывает утвержденный стек технологий, архитектуру компонентов и инструкцию по запуску веб-платформы визуального мониторинга яблоневого сада без бэкенда.

---

## 1. Стек технологий (Tech Stack 2026)

| Категория | Выбранная технология | Версия | Обоснование |
|---|---|---|---|
| **Ядро & Сборка** | **Vite + React + TypeScript** | React 19, TS 5+, Vite 6 | Мгновенный HMR (10-30 мс), строгая типизация данных секторов и телеметрии, статический билд без серверных зависимостей. |
| **Стилизация** | **Tailwind CSS** | v4 | Утилитарные классы, CSS-переменные для темно-изумрудной темы, поддержка Backdrop Filter (Glassmorphism). |
| **Иконки** | **Lucide React** | Latest | Легкие древовидные SVG-иконки: `Leaf`, `Map`, `Database`, `TrendingUp`, `Bell`, `Settings`, `Sun`, `Plane`, `Headphones`, `ArrowRight`. |
| **Анимации** | **Motion (Framer Motion)** | Latest | Декларативные анимации переключения экранов (`AnimatePresence`), плавный hover карточек, покачивание дрона. |
| **Сглаженный скролл** | **Lenis** | Latest | Ультра-плавный скроллинг при переходе к длинным отчетам или карте. |
| **Интерактивная карта** | **SVG / Canvas Engine** | Custom | Легковесная карта секторов сада с зумом, подсказками и шкалой зрелости без тяжелых картографических сервисов. |

## 3. Команды для инициализации и запуска

При инициализации проекта в каталоге `E:\intellia-garden`:

```bash
# 1. Установка зависимостей (React, Tailwind, Motion, Lucide)
npm i lucide-react motion lenis clsx tailwind-merge

# 2. Запуск в режиме разработки
npm run dev

# 3. Сборка статического продакшн-бандла
npm run build
```

## 4. Требования к UI & UX
1. **60-120 FPS:** Все анимации запускаются на GPU (`transform`, `opacity`).
2. **Адаптивность:** На мобильных устройствах сайдбар аккуратно сворачивается в мобильное меню или нижний таб-бар.
3. **Состояние экранов:** Навигация между «Главная», «Карта сада», «Данные» и «Прогнозы» происходит мгновенно без перезагрузки страницы.
